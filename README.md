# coredot-print-central

여러 키오스크의 카드 인쇄를 **중앙 PC 한 곳에서 번호 순서대로 받아**, 키오스크 PC 들에 꽂힌 프린터로
나눠 뽑는 프로그램입니다. 키오스크 사이트가 완성한 카드 그림을 그대로 인쇄합니다.

**설치할 것이 없습니다.** 아래 exe 를 받아 더블클릭하면 됩니다 (Python · Node · Redis 불필요).

## 받기

[**Releases**](../../releases/latest) 에서 필요한 것만 받습니다.

| 어느 PC | 받을 것 | 바로 받기 |
|---|---|---|
| 중앙 PC (행사장에 한 대, 프린터 없어도 됨) | `central.exe` | [central.exe](../../releases/latest/download/central.exe) |
| 키오스크 PC (프린터가 꽂혔든 아니든) | `kiosk.exe` | [kiosk.exe](../../releases/latest/download/kiosk.exe) |
| (행사 전 시험만) | `loadtest.exe` | [loadtest.exe](../../releases/latest/download/loadtest.exe) |

키오스크 PC 에서 **코어닷프린트**(프린터서버)를 이미 쓰고 있다면 `kiosk.exe` 대신 그것을 써도 됩니다 —
[코어닷프린트 Releases](https://github.com/CoreDotToday/coredot-printer-v2/releases) 의 2.10 이상, "중앙제어" 탭.
**한 PC 에서 둘을 같이 켜면 안 됩니다** (같은 8000 번을 써서 인쇄가 엉킵니다).

> 처음 실행할 때 윈도우가 "PC 보호" 창을 띄우면 **추가 정보 → 실행** 을 누르세요 (서명하지 않은 exe 라서 뜨는 창입니다).
> exe 는 **폴더 하나에 넣어 두고** 쓰세요 — 설정 · 기록이 exe 옆에 생깁니다. 새 판으로 바꿀 때도 같은 폴더에 덮어쓰면 기록이 이어집니다.

## 쓰는 법

### 1. 중앙 PC — `central.exe`

1. 더블클릭 → 윈도우 방화벽이 물으면 **허용** (키오스크 PC 가 이 PC 의 8000 번으로 들어옵니다)
2. 창 없이 돌고, 브라우저에 대시보드가 열립니다 (`http://localhost:8000`)
3. 브라우저를 닫았으면 **`central.exe` 를 다시 더블클릭** — 이미 돌고 있으면 대시보드만 다시 엽니다
4. 끄기: 대시보드 **설정 → 중앙 끄기** (중앙 PC 자신의 화면에서만 보입니다). 다시 켜면 기다리던 카드가 그대로 이어집니다

대시보드는 맨 위 상태 줄 · **지금 확인할 것** · 탭 넷(운영 / 로그 / 통계 / 설정)입니다. 평소에는 "지금 확인할 것"만 보면 되고,
무슨 일이 있었는지는 **로그** 탭에 중앙과 키오스크 PC 의 일이 모두 모입니다.

기록 · 백업은 exe 옆 `data` · `logs` · `backups` 폴더에 쌓입니다 — 지우지 마세요.

### 2. 키오스크 PC — `kiosk.exe`

1. 더블클릭 → 중앙 PC 주소(비워 두면 같은 네트워크에서 저절로 찾습니다)와 이 키오스크의 종류(1 포토카드 / 2 스티커)를 답합니다
2. 화면에 **4자리 연결 번호**가 뜹니다
3. 중앙 대시보드 **🖥 키오스크 PC → 연결 기다리는 PC** 에서 그 PC 이름 옆에 번호를 칩니다 — 처음 한 번만
4. 창을 **켜 둡니다** — 닫으면 이 PC 의 인쇄가 멈추고, 카드는 다른 PC 의 프린터로 넘어갑니다

키오스크 사이트는 고칠 것이 없습니다 (사이트는 늘 `http://localhost:8000` 으로 보내고, `kiosk.exe` 가 중앙으로 넘깁니다).

### 3. 다른 PC · 폰에서 대시보드 보기

브라우저로 `http://<중앙PC주소>:8000` → 화면에 4자리가 뜹니다 → 중앙 PC 대시보드의 **🖥 허용된 화면** 에서 그 번호를 칩니다.

## 행사 당일 순서

1. 중앙 PC: `central.exe`
2. 키오스크 PC 마다: `kiosk.exe` (또는 코어닷프린트의 중앙제어)
3. 키오스크 사이트를 크롬으로 엽니다
4. 대시보드에서 확인
   - 키오스크 PC 가 모두 **연결됨**
   - 운영 탭의 종류마다 **+ 프린터** 로 그 용지가 든 프린터를 더하고, 프린터 칸의 **⋯** → **시험 인쇄** 한 장
   - 맨 위 상태 줄이 모두 초록, **지금 확인할 것 없음**
   - 맨 위에 빨간 띠(가짜 프린터)가 없는지
   - 리허설 기록은 **🗑 초기화** (통계는 남습니다)

## 카드가 안 나올 때

| 보이는 것 | 할 일 |
|---|---|
| 작업이 **확인 필요** | 프린터 전원 · 용지 · 리본 · 덮개. 고치면 그 카드가 그대로 나옵니다 — 이때 재출력하면 두 장이 됩니다 |
| 키오스크 PC 가 **끊김** | 그 PC 의 `kiosk.exe` 창이 꺼져 있습니다. 그동안 카드는 다른 PC 의 프린터로 갑니다 |
| 대시보드 **연결 실패** | 중앙 PC 의 `central.exe` 가 꺼졌습니다. 다시 더블클릭하면 몇 초 안에 돌아옵니다 |
| `central.exe` 를 눌렀는데 "포트를 다른 프로그램이 쓰고 있다" | 그 PC 에서 코어닷프린트가 8000 을 쓰는 중 — 끄거나 그쪽 포트를 8001 로 |
| 무엇이 있었는지 알고 싶다 | 대시보드 **로그** 탭 — 오류만 / PC 별로 거를 수 있습니다. 지난 날은 중앙의 `logs/events-날짜.jsonl` |
| 키오스크 PC 가 중앙을 못 찾음 | 중앙 PC 방화벽에서 8000(TCP) · 38000(UDP) 허용, 또는 `kiosk.exe` 옆 `relay.ini` 의 `print_server` 에 중앙 주소 |
| `kiosk.exe` 가 "8000 을 이미 쓰고 있다" | 그 PC 에서 코어닷프린트가 켜져 있습니다 — 하나만 쓰세요 |

## 부하 시험 (행사 전에만)

`loadtest.exe` 를 키오스크 PC 의 `kiosk.exe` 와 **같은 폴더**에 두고 실행 → `1 카드 보내기` / `2 결과 확인`.
빠진 장 · 두 장 나간 장이 0 이어야 통과입니다.
